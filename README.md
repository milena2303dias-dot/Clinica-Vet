# VetAgenda 🐾

**VetAgenda** é um projeto acadêmico de desenvolvimento web que consiste em um sistema de gerenciamento de agendamentos para uma clínica veterinária. O projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web, organização de dados, modelagem de banco de dados e construção de interfaces.

## 🎯 Objetivo

Desenvolver uma aplicação web que facilite a organização dos dados de tutores, pets e veterinários, além do gerenciamento de consultas veterinárias, reunindo essas funcionalidades em uma interface simples e organizada.

## ⚙️ Funcionalidades

- Cadastro de tutores;
- Cadastro de pets e associação com seus tutores;
- Cadastro de veterinários;
- Gerenciamento de agendamentos;
- Organização das informações por meio de páginas específicas;
- Interatividade utilizando JavaScript.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura das páginas;
- **CSS3** — estilização e organização visual;
- **JavaScript** — interatividade e funcionalidades do sistema;
- **MySQL** — estudo e modelagem de banco de dados.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram trabalhados conceitos de estruturação HTML, estilização com CSS, manipulação de elementos com JavaScript, organização de arquivos, modelagem de dados, relacionamentos entre entidades e lógica de funcionamento de um sistema.

O projeto também contribuiu para o desenvolvimento da capacidade de resolver problemas, compreender a relação entre diferentes partes de uma aplicação e transformar requisitos em funcionalidades.

## 🚀 Projeto acadêmico

O VetAgenda foi desenvolvido como parte do processo de aprendizado em desenvolvimento de sistemas, reunindo conhecimentos teóricos e práticos em um projeto aplicado.
